# 🛡️ Analytics Based Cyber Threat Detection System

A Python-based data analytics and interactive dashboard project that analyzes real-world state-level cybercrime data.

## 🎯 Project Objective

The goal is to analyze cybercrime patterns, identify major threat categories, compare States/UTs, study digital fraud, and create a project-specific analytical threat risk score.

## 📊 Dashboard Modules

- Executive Dashboard
- State Intelligence
- Threat Intelligence
- Risk Intelligence
- Data Explorer
- Project Overview

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 🔄 Workflow

Raw Dataset → Data Cleaning → Exploratory Data Analysis → Threat Analysis → Risk Scoring → Interactive Dashboard

## ▶️ Run the project

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Or on Windows, double-click:

`run_dashboard.bat`
